# Imagens provisórias

As ilustrações SVG desta pasta foram produzidas para esta primeira implementação do layout. Não são fotografias nem imagens oficiais de sessões, documentos ou equipamentos específicos.

Substitua-as pelas fotografias autorizadas e pelo logotipo original do projeto para reproduzir integralmente a referência visual. Os downloads externos de fotografias foram bloqueados pela política de rede do ambiente durante esta implementação.
